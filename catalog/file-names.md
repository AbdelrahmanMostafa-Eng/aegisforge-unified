# SKILL.md Filename Catalog

This catalog maps the major repository folders to possible skill names. Names are normalized as lowercase `kebab-case` slugs. If each skill is stored as a separate file, use `<skill-name>.md`. If following the common directory-based convention, use `<skill-name>/SKILL.md`.

The catalog is designed to be broad and extensible. It lists practical skill names rather than claiming that a finite document can contain every future skill ever invented.
